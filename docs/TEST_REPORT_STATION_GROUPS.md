## 改动

固定6/8字段的增量分帧和严格解析；组别原样文本保存；检测结果/总结果与LOGO、火焰均要求OK/NG，服务器不覆盖上报结果。JSON v2仍为旧worker_id兼容路径。四工位路由仍按项目+工位，组别不参与标准选择。管理页/只读页显示新列，筛选包含新结果NG，CSV/JSONL导出新字段，旧工号只留在旧记录和导出中。

工位schema升级至3：旧库先独立备份，新增可空group_id、detection_result、total_result，DDL事务失败回滚。旧记录无新字段的值，不把worker_id变成group_id，不回填OK/NG，保留原始报文、ID、标准快照、去重回执。标准JSON清单与分工位选择保留。未修改现场数据、凭据或服务。
