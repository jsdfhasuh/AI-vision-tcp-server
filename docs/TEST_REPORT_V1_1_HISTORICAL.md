## 3. 浏览器渲染与状态检查

测试脚本：`tests/browser_smoke.py`。此次命令：

```text
python tests/browser_smoke.py --browser /usr/bin/chromium --content-bridge
```

完成 18 项状态/交互检查，无 JavaScript 页面异常；详情在 `tests/browser_smoke_v1_1.json`。

测试内容包括：实时页不自动生成数据、模拟控件在实时页隐藏；两个赛项各 10 次真实 TCP 报文提交到引擎和 HTTP 后更新 DOM；公共响应无预设答案和接入码；等待中计时；取消/超时独立显示；参赛端断线；发布线程繁忙导致快照过期；网页请求故障不使用演示数据；恢复更新；队名中的 HTML 只显示为文本；独立演示有醒目标识；主题和赛项切换；演示的等待/超时/掉线/迟到/取消/中断状态；全屏按钮与 F 键。

**环境限制：**容器内浏览器导航受到管理策略限制，未能直接导航到文件或本机 HTTP 地址。因此使用 Playwright `set_content` 加载实际 HTML/CSS/JS，在测试页中将 `fetch` 桥接到 Python HTTP 客户端；桥接仍向运行中的真实展板 HTTP 服务请求，服务端数据来自真实 TCP 套接字。此方式验证渲染、前端状态和公共数据链路，但**不等同于浏览器直接访问时的同源策略、CSP、原生 Fetch 取消、浏览器缓存、Windows 端浏览器及防火墙验收**。生产源码不包含此测试桥接。

正常无导航限制的测试环境可不传 `--content-bridge`，执行真实浏览器导航测试。Playwright 仅是可选测试依赖，运行裁判服务端和网页不需要安装它。
