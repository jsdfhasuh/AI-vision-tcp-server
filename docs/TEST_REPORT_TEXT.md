# 简单文本 TCP 扩展：实施与测试记录

基线：`4cdee4123034cb539d28bd90f18f7b949fde4f73`。保留批量JSON标准清单、分工位选择、历史快照、四工位映射、登录保护和Windows备份修复。

## 实现范围

- 新增`competition/station_text.py`：固定字段数的UTF-8纯文本解析，`end`结尾，按字段位置识别结束而不是扫描条码中的end子串；原样保留工号/条码文本，明确拒绝无法承载的逗号。
- `competition/station_runtime.py`接入新分帧器；文本与旧JSON v2按连接选择并固定格式，共用现有工位连接归属、存储和页面数据接口。成功提交数据库后才发`ACK,end`。格式错误、未收到完整数据或存储故障均不伪造NG。
- 每条文本报告分配新的内部记录标识；相同文本连续到达也分别记录，不做内容去重。文本客户端不自动重试；JSON v2的原msg_id去重保留。
- `station_client.py`命令行默认文本；显式`--json-v2`保留旧调试方式，原`send_result()`供旧调用方使用。新增`send_text_result()`，有超时、拆分回执处理及结果未知提示。
- 界面、JSON批量导入和数据库schema没有改动。不增加评分、轮次、目标下发或型号文字识别。
