## 实现

批量JSON标准清单、最多1000条且256 KiB、原单条格式兼容；两个包装箱工位分别选择标准，不按白名单任意命中。整批导入原子化、重复ID拒绝、编号/条码变化清除受影响选择。工位选择与标准清单共用版本冲突保护，历史存储标准编号/名称/条码/版本。旧工位数据库先备份再事务升级至schema v2，原始结果不重写。

前端增加清单预览/查找和每工位的选择/应用控件，轮询保留待导入文件与未应用选择，不重建正在操作的原生下拉框。公共接口/展板不公开清单或所选标准，TCP消息完全不变。
